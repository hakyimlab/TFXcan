Introduction

The aim of this project here is to test concordance of predicted binding with

  • observed TF expression-gene expression correlation e.g. co-expression

  • predicted TF binding-gene expression correlation

  • prediXcan trans-acting gene relationships from https://onlinelibrary.wiley.com/doi/10.1002/gepi.22205

qqunif.ggplot <- function(p, mlog10_p_thres=30, pch = NULL){
    require(ggplot2)
    ## thresholded by default at 1e-30
    p=na.omit(p)
    nn = length(p)
    xx =  -log10((1:nn)/(nn+1))
    
    p_thres = 10^{-mlog10_p_thres}
    if(sum(p < p_thres)){
      warning(paste("thresholding p to ", p_thres))
      p = pmax(p, p_thres)
    }

    dt <- data.table(pval = xx, dist = -sort(log10(p)))

    if(is.null(pch)){
        pch <- 19
    }

    pp <- ggplot2::ggplot(dt, aes(x = pval, y = dist)) +
        geom_point(pch = pch) +
        labs(x = expression(Expected~~-log[10](italic(p))),
          y = expression(Observed~~-log[10](italic(p)))) +
          geom_abline(aes(intercept = 0, slope = 1), col='gray', lty = 1)
        
    return(pp)
}

qqcompare.ggplot <- function(p1, p2, names = c('observed', 'null'), mlog10_p_thres=30, pch = NULL){
    require(ggplot2)
    ## thresholded by default at 1e-30
    p1 = na.omit(p1)
    p2 = na.omit(p2)
    p_thres = 10^{-mlog10_p_thres}
    if(!is.null(p_thres)){pvec1 = pmax(p1, p_thres); pvec2 = pmax(p2, p_thres)}
    nn = length(pvec1)
    xx =  -log10((1:nn)/(nn+1))

    if(is.null(pch)){
        pch <- 19
    }

    pp <- ggplot2::ggplot() +
        geom_point(aes(x = xx, y = -sort(log10(pvec1)), col = names[1]), pch = pch) +
        geom_point(aes(x = xx, y = -sort(log10(pvec2)), col = names[2]), pch = pch) +
        labs(x = expression(Expected~~-log[10](italic(p))),
          y = expression(Observed~~-log[10](italic(p)))) +
          geom_abline(aes(intercept = 0, slope = 1), col='gray', lty = 1)
        
    return(pp)
}

Prompts

I have 3 datasets: 1. correlation of TF gene expression and other non-TF genes across GEUVADIS individual in LCL cell lines.

2. correlation of predicted TF binding at the promoter of genes and the expression of the downstream gene in Blood.

3. PrediXcan association of trans-acting genes and their likely target genes (paper: https://onlinelibrary.wiley.com/doi/10.1002/gepi.22205)

Analysis

Preparation: restrict to trans TFs and remove cis target genes

All analyses are restricted to TF genes that appear as trans-acting genes in the PrediXcan dataset (DS3). Cis target genes — on the same chromosome and within 1 Mb of the TF gene — are removed from all three datasets using genomic coordinates sourced from DS3 (for TF loci) and tss_metadata (for target gene loci).

cis_window_bp <- 1e6  # 1 Mb

# Remove cis pairs: keep pairs where TF and target are on different chromosomes
# or separated by more than cis_window_bp. Pairs with no target coordinate are kept.
filter_cis <- function(dt, tf_coords, target_coords, cis_window = cis_window_bp) {
    dt %>%
        dplyr::inner_join(tf_coords, by = 'tf_gene') %>%
        dplyr::left_join(target_coords, by = 'target_gene') %>%
        dplyr::filter(
            is.na(target_chr) |
            tf_chr != target_chr |
            abs(tf_pos - target_pos) > cis_window
        ) %>%
        dplyr::select(-tf_chr, -tf_pos, -target_chr, -target_pos)
}
